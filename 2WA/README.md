2WA (*short for "To Web Assembler"*) is a transpiler project that converts supported programming languages into WebAssembler instructions for a lightweight virtual machine runtime.

The project focuses on experimenting with language transpilation, runtime execution, and browser-oriented low-level instruction generation.

Some language implementations are currently being developed, while others are planned for future support.

### <a name="c"></a>C <sup>[top⇈](#contents)</sup>

> C is a general-purpose systems programming language focused on performance, portability, and low-level memory access.

* [c2wa](https://github.com/PoTiwi/WebAssembler/tree/main/2WA/C) - transpiles C source code into WebAssembler instructions for the 2WA runtime.

--------------------

### <a name="c-1"></a>C++ <sup>[top⇈](#contents)</sup>

> C++ is a general-purpose programming language that extends C with object-oriented, generic, and higher-level programming features.

* [cpp2wa](https://github.com/PoTiwi/WebAssembler/tree/main/2WA/C++) - experimental C++ transpiler targeting the 2WA runtime.

--------------------

### <a name="javascript"></a>JavaScript <sup>[top⇈](#contents)</sup>

> JavaScript is a high-level scripting language commonly used for web applications and browser environments.

* [js2wa](https://github.com/PoTiwi/WebAssembler/tree/main/2WA/JavaScript) - planned JavaScript transpiler for the 2WA runtime.

--------------------

### <a name="python"></a>Python <sup>[top⇈](#contents)</sup>

> Python is a high-level general-purpose programming language focused on readability and rapid development.

* [py2wa](https://github.com/PoTiwi/WebAssembler/tree/main/2WA/Python) - planned Python transpiler for the 2WA runtime.

--------------------

### <a name="lua"></a>Lua <sup>[top⇈](#contents)</sup>

> Lua is a lightweight scripting language commonly used for embedded systems, games, and runtime scripting.

* [lua2wa](https://github.com/PoTiwi/WebAssembler/tree/main/2WA/Lua) - planned Lua transpiler for the 2WA runtime.

### <a name="aarch64-assembly"></a>(AArch64) Assembly <sup>[top⇈](#contents)</sup>

* [a64asm2wa](https://github.com/PoTiwi/WebAssembler/tree/main/2WA/A64Assembly) - planned AArch64 Assembly transpiler for the 2WA runtime.
